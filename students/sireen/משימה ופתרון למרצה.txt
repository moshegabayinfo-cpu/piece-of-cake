המשימה של סירין: הודעת שגיאה ברורה לכמות
בקוד השרת כבר קיימת בדיקת טווח 1–20. שפרי את הטיפול בערך שאינו מספר שלם כדי להציג שגיאה ברורה בעברית, בלי לפגוע ביתר הבדיקות.
קובץ: app.py; אפשר להוסיף בדיקה ב-tests/test_app.py.
בדיקות: 0, 21 ו-abc נדחים בלי יצירת הזמנה; 2 נשמרת כאשר יתר הפרטים תקינים.






























פתרון מפורט למרצה
====================
1. בתוך הפונקציה order שב-app.py מצאי בתוך בלוק ה-try את השורה:
quantity = int(request.form.get("quantity", "0"))

2. החליפי רק אותה בבלוק הבא, באותה רמת הזחה שבה הייתה השורה המקורית:
try:
    quantity = int(request.form.get("quantity", ""))
except ValueError:
    raise ValueError("יש להזין כמות שלמה בין 1 ל-20") from None

3. השאירי את בדיקת הטווח הקיימת ואת בלוק except ValueError החיצוני: הוא שומר את ההודעה ב-error והתבנית מציגה אותה. אל תסירי את בדיקות השם, התאריך והכתובת.
4. הריצי את האתר ונסי 0 ו-21. כדי לבדוק abc, שאותו דפדפן עשוי לחסום בשדה מספרי, השתמשי בבדיקה אוטומטית או בבקשת POST מבוקרת עם אסימון CSRF תקין.
5. דוגמה להרחבת בדיקה קיימת ב-tests/test_app.py, לאחר יצירת client מתאים:
def test_quantity_non_numeric_message(client):
    response = submit(client, quantity="abc")
    assert response.status_code == 400
    assert "יש להזין כמות שלמה בין 1 ל-20" in response.get_data(as_text=True)
    assert saved_order() is None
