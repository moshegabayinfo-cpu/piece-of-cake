המשימה של לוסיאן: שיפור תצוגה בטלפון
שפרי את התצוגה ברוחב 360 פיקסלים: ניווט קריא, קטלוג וטופס בעמודה אחת, כפתורים נוחים וטבלת ניהול שנגללת אופקית. שמרי על מראה תקין במחשב.
קובץ: static/style.css; לפי הצורך templates/base.html.
בדיקות: קטלוג, טופס וניהול ברוחב 360 וכן במסך מחשב.






























פתרון מפורט למרצה
====================
1. פתחי static/style.css ושימי לב שכבר קיימת media query לרוחב 750 פיקסלים: הקטלוג והטופס מוגדרים לעמודה אחת. הרחיבי אותה או הוסיפי כלל נוסף בסוף הקובץ.
2. דוגמה לשיפור ממוקד:
@media (max-width: 420px) {
    header { padding: 16px 5%; gap: 12px; }
    nav { flex-wrap: wrap; gap: 12px 18px; }
    main { padding: 20px 5% 40px; }
    .catalog, .order-form { grid-template-columns: minmax(0, 1fr); }
    .order-form { padding: 16px; gap: 14px; }
    .wide { grid-column: 1 / -1; }
    .button, button { min-height: 44px; }
    .table-wrap { max-width: 100%; overflow-x: auto; }
}

3. פתחי DevTools בדפדפן והפעילי תצוגת מכשירים. בחרי רוחב 360 ובדקי את הקטלוג ואת טופס ההזמנה. במסך הניהול גללי את הטבלה בתוך האזור שלה; אין צורך לדחוס את כל העמודות לתוך המסך.
4. בדקי שאין גלילה אופקית לכל הדף, שהקישורים והכפתורים נגישים ושאפשר לשלוח טופס. בדקי שוב גם ברוחב מחשב. אם תוכן אמיתי עדיין גולש, התאימי את הכללים לפי הממצא במקום להסתיר אותו.

Git והגשה: עדכני main, צרי את הענף האישי שנשלח במייל, שמרי שינויים, בצעי commit ו-push ופתחי Pull Request לבדיקה. אל תעלי את .env או את .venv.
