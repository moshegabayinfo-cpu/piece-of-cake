המשימה של תולין: אזור היכרות עם החנות
הוסיפי אזור ״קצת עלינו״ בין הפתיחה לרשימת העוגות: כותרת, שני משפטי היכרות ואזכור של משלוח או איסוף עצמי. הטקסט הוא דוגמה לימודית; אין להבטיח שירותים שלא קיימים.
קובץ: templates/catalog.html; לפי הצורך static/style.css.
בדיקות: האזור מופיע, הקטלוג עדיין מוצג ונוח לקרוא אותו בטלפון.






























פתרון מפורט למרצה
====================
1. פתחי templates/catalog.html. מצאי את סיום section של ה-hero ואת הכותרת ״העוגות שלנו״.
2. לפני הכותרת הוסיפי אזור עצמאי:
<section class="about-shop" aria-labelledby="about-title">
    <h2 id="about-title">קצת עלינו</h2>
    <p>ב-Piece of Cake אנחנו אוהבות להפוך רגעים קטנים לחגיגה מתוקה.</p>
    <p>בחרו עוגה מהקטלוג והזמינו באיסוף עצמי או במשלוח.</p>
</section>

3. אם תרצי לעצב אותו, הוסיפי בסוף static/style.css:
.about-shop {
    padding: 20px 24px;
    margin-bottom: 28px;
    background: #fff;
    border: 1px solid #e5d8cf;
    border-radius: 12px;
}
.about-shop h2 { margin-top: 0; }

4. שמרי ופתחי את הקטלוג דרך Flask. ודאי שהאזור נמצא לפני העוגות, שהקישורים להזמנה פועלים ושהטקסט אינו נחתך ברוחב 360 פיקסלים. section ו-h2 עוזרים לתאר את מבנה התוכן.

Git והגשה: עדכני main, צרי את הענף האישי שנשלח במייל, שמרי שינויים, בצעי commit ו-push ופתחי Pull Request לבדיקה. אל תעלי את .env או את .venv.
